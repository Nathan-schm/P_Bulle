pour les pairs on utilise le modulo % en gros la division.
si on fait 3 % 2 bah c pas paire vu que il nous reste 1, genre on peut faire 2 % 2 mais pas 3 % 2
donc si on fait 2 % 2 bah io marchera
donc dans l'exo on l'utilisera comme ceci :
let x = code % 2;
returne x === 0;

le let c'est pour créer une variable x qui à comme valeur code modulo 2 pr voir si c'est pairs ou pas
et le === 0 c'est pr savoir si à la fin du modulo on arrive à 0.
